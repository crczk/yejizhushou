# 业绩助手 - Gitee 云存储网页 APP v3

这是一个可以部署成网址使用的手机网页 APP / PWA。数据保存在浏览器本地，并可同步到 Gitee 私有仓库中的 JSON 数据文件。

## v3 主要变化

- 新增账号注册与登录：未登录时不能记录业绩，也不能从 Gitee 拉取或上传数据。
- 新增普通用户 / 管理员权限：普通用户只能查看、修改、导出自己的业绩；管理员可查看与管理所有用户、成员、业绩类型和全部业绩记录。
- 新增默认管理员账号：账号 `admin`，初始密码 `admin123`。上线后请立即在“我的 → 当前账号”中修改密码。
- 新增用户账号管理：管理员可停用 / 启用账号、重置密码、设置管理员或普通用户。
- 导出能力升级：新增“导出 Excel”，表格中包含业绩类型汇总、全部明细记录，并按同一业绩类型列出每一次上传记录及该类型总数。
- 移除页面中的“导出 JSON”按钮，保留 Gitee 云同步所需的数据文件格式。
- 日期显示改为本地日期计算，修复跨时区或凌晨后仍显示昨天的问题。
- 普通用户清空数据时只会清空自己的记录；管理员清空数据时才会清空全部记录。

## 部署方式

把以下文件上传到 Gitee Pages、宝塔网站目录、Nginx 静态站点或任意静态网站空间：

```text
index.html
styles.css
app.js
manifest.webmanifest
sw.js
icon.svg
```

然后用手机浏览器打开网址即可使用。安卓 Chrome / Edge 或 iPhone Safari 可以添加到手机主屏幕。

## 初次使用

1. 打开网页后，使用默认管理员账号登录：
   - 账号：`admin`
   - 密码：`admin123`
2. 登录后进入“我的 → 当前账号”，先修改管理员密码。
3. 管理员可在“我的”页面维护业绩类型、成员和用户账号。
4. 普通用户可直接在登录页注册自己的账号。注册后系统会自动创建与该账号绑定的成员档案。

## Gitee 数据仓库

建议单独创建一个私有仓库，例如：

```text
performance-data
```

在仓库中创建数据文件：

```text
data/performance.json
```

可以先复制 `data-format.json` 的内容作为初始数据。

## APP 中的 Gitee 配置

进入：

```text
我的 → Gitee 数据同步设置
```

填写：

```text
Gitee 用户名/组织：你的 Gitee 用户名
仓库名：performance-data
分支：master 或 main
数据路径：data/performance.json
Access Token：你的 Gitee 私人令牌
```

登录后才可以执行“从 Gitee 拉取”和“上传/覆盖到 Gitee”。普通用户上传时，程序会尽量保留远端其他用户数据，只合并当前登录用户自己的记录；管理员上传则以管理员当前看到的完整数据为准。

## Excel 导出说明

进入“我的 → 数据工具”，点击“导出 Excel”。导出的 `.xls` 文件可用 Excel / WPS 打开，内容包括：

- 业绩类型汇总：每一项业绩类型的总数和上传笔数。
- 全部明细记录：每次上传的日期、成员、类型、数值、备注、上传时间。
- 按业绩类型分组：同一项业绩类型下列出每一次上传数据，并在末尾显示该类型汇总。

普通用户导出的是本人数据；管理员导出的是全部数据。

## 数据安全提醒

这是纯前端方案，账号、密码哈希、Gitee Access Token 与业务数据会保存在浏览器本地和你配置的 Gitee 数据文件中。它适合个人使用、内部使用、小范围使用。正式多人生产环境建议增加后端服务，由后端负责登录鉴权、数据隔离和 Token 托管。

## 数据格式说明

请看 `data-format.json`。核心结构如下：

```json
{
  "version": 3,
  "users": [],
  "members": [],
  "types": [],
  "records": [],
  "updatedAt": "2026-06-02T00:00:00.000Z"
}
```

- `users`：登录账号列表，包含账号、昵称、角色、关联成员和密码哈希。
- `members`：成员列表。
- `types`：业绩类型列表。
- `records`：业绩记录，每条记录关联一个成员和一个业绩类型。
- `updatedAt`：最后更新时间。
